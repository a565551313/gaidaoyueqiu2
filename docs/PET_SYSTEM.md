> 当前代码包含五只宠物档案、详情/携带交互、存档成长字段与局内效果运行时。下文的“已实现”指源码中存在相应配置或逻辑，不代表经过完整的自动化、浏览器或真实设备验收。`scripts/verify.mjs` 当前不包含宠物专项回归；真实手机触控与安全区检查也尚未完成。

> 未发现同类的 chapterMode 不可达问题，但同样没有专项自动化回归，仍按下文免责声明理解。

## 1. 当前功能范围

- 主菜单可进入宠物页；宠物页提供列表、详情、携带/取消携带、升级经验和星阶突破相关界面与操作。
- 五只宠物都有等级、经验、星阶、拥有状态及技能配置；首次开局读取当前携带宠物的等级/星阶快照，局内由 `PetRuntime` 读取该快照。
- 结算逻辑按参与情况授予经验；放弃对局不授予宠物经验。上述流程来自代码实现，尚无宠物专项自动化断言。
- 宠物造型由 `src/components/AnimatedPet.vue` 内的 SVG 与 CSS 动画提供，不依赖外部宠物图像资源。

## 2. 当前实现

### 2.1 宠物档案与效果

定义位于 `src/data/pets.js`，效果计算与运行时位于 `src/core/petSystem.js`。

| 宠物 | 解锁条件（总关卡星数） | 代码中的效果类型 |
| --- | ---: | --- |
| 月岩兔 | 默认拥有 | 扩大完美判定窗口；三星起可积累一次连携窗口强化；五星有一次近似完美修正 |
| 云母精灵 | 3 星 | 缩短天气持续时间；三星起降低天气开场强度；五星抵消一次楼体雷击 |
| 铆钉犬 | 6 星 | 旧设备识别、事件充能和致命拦截均已退役；不提供蚁群免切、护盾、抗性或伤害减免 |
| 燧星狐 | 10 星 | 若干次手动落层后额外充能；三星起烈焰结束可恢复宽度；五星首次释放烈焰后获得免切护层 |
| 星辉猫 | 15 星 | 提高金币收益；旧施工事件额外金币已退役；五星三星通关有额外金币倍率 |

每只宠物的具体效果数值会随等级和星阶变化，使用 `resolvePetEffects()` 计算。表中概括效果种类，不是对每个边界条件均已测试的声明。

### 2.1 已退役技能与蚂蚁边界

施工设备事件已经由蚂蚁敌人系统替代，旧设备点击、事件充能、致命事件拦截和事件额外金币运行时均已移除。对应宠物技能条目保留作存档/档案兼容，并在页面明确标为已退役；铆钉犬与星辉猫不会对蚂蚁造成伤害、降低蚁伤、提供抗性/免切或击退奖励。

| 宠物旧能力 | 当前状态 | 蚂蚁系统边界 |
| --- | --- | --- |
| 铆钉犬设备识别与事件充能 | 已退役，不扩大任何点击区、不增加充能 | 不改变蚂蚁目标、咬击、HP 或扫描结算。 |
| 铆钉犬致命结构拦截 | 已退役，无自动拦截 | 不提供蚁群护盾、免切、抗性或固定伤害减免。 |
| 星辉猫事件回收金币 | 已退役，蚂蚁击退不触发金币奖励 | 仅保留常规金币倍率及三星通关倍率。 |
| 月岩兔确定性完美辅助 | 公开影响当前落层的确定性完美窗口 | 随机完美不会升级蚂蚁震击品质；落层品质仍依原始重叠与几何窗口判定。 |
| 云母精灵与燧星狐 | 保持天气与烈焰/宽度原用途 | 天气宠物效果不命中蚂蚁；烈焰/免切只保护塔体。 |



### 2.2 页面和动画

- 路由组件：`src/components/PetCenter.vue`；动画组件：`src/components/AnimatedPet.vue`。
- 列表展示拥有/锁定状态、携带状态、等级经验、星阶和技能摘要；详情显示技能与突破条件，并提供携带、取消携带和满足条件后的星阶突破操作。
- 携带宠物也会以小型动态徽章出现在游戏 HUD。宠物运行时的提示序号可触发动画反馈。
- SVG/CSS 中包含呼吸、漂浮、眨眼及局部动作/触发反馈等实现。随机眨眼节奏、定时器清理、不同屏幕上的动画体验尚未由宠物专项测试验证。

### 2.3 存档与旧数据兼容

实现位置：`src/core/storage.js`、`src/core/store.js`。

```js
pets: {
  moonRabbit: { owned: true, level: 1, exp: 0, star: 1 },
  // 其余宠物按定义补齐
},
activePetId: 'moonRabbit'
```

- 存档键为 `gaidaoyueqiu2:save:v1`，当前后端是 `localStorage`；默认值与旧字段通过深度合并补齐。
- `normalizePets()` 会根据旧存档的关卡总星数同步满足门槛的宠物拥有状态，并把星阶、等级、经验收敛到允许范围；无效或未拥有宠物的 `activePetId` 会清空。
- `Storage.load()` 还把旧版 `settings.volume` 作为 `musicVolume` 与 `effectsVolume` 的缺省值。主题切换已取消：应用固定为深色，默认存档不含 `theme` 字段。
- 宠物等级上限为当前星阶 × 10，最高 50 级；升阶费用在 `src/data/pets.js` 配置为 2 星 500、3 星 1000、4 星 1800、5 星 3000 金币。
- 通关和失败结果均可按参与程度授予经验；放弃结果的经验为 0。实际升级过程在 `actions.grantPetExp()` 中处理。

这些兼容与边界规则可由代码检查确认，但目前未见针对宠物字段迁移、解锁、等级经验溢出、升阶、携带快照和结算经验的自动化测试。

### 2.4 单局运行时

`createPetSnapshot()` 根据当前携带宠物及其存档等级/星阶生成当局快照，`PetRuntime` 在局内维护一次性效果状态和提示。相关接入点包括 `src/components/GameView.vue`、`src/core/gameEngine.js`、`src/core/weather.js` 与 `src/core/antSystem.js`。

代码覆盖的效果类别包括完美判定窗口、天气持续时间/开场强度、天气偏转、额外充能、烈焰后修补/护盾，以及结算金币和经验；退役事件技能不再有局内钩子。具体效果的数值正确性、与其他技能/道具的交互及运行时表现尚未由宠物专项自动化覆盖。

## 3. 资源与许可证

当前宠物造型为项目内 SVG 实现，没有发现被宠物组件直接引用的外部宠物图片包。曾列入计划的 Kenney 动物资源仍是参考候选，不是当前宠物美术依赖。项目其他实际资源及仓库内许可证记录见根目录 [`ASSET_LICENSES.md`](../ASSET_LICENSES.md)。该登记区分仓库随附声明和外部独立核验；本文件不对外部资源许可作额外保证。

## 4. 保留的后续计划

以下是旧版规划条目，保留供后续评估，不表示已排期或承诺实现。

### P0：验收与补强

1. 在真实手机尺寸检查列表、详情、HUD 的触控区域与安全区。
2. 评估是否为五只宠物补充更明确的技能事件动作。
3. 增加动画组件测试，覆盖随机眨眼、触发动作重置和卸载后的定时器清理。
4. 增加回归测试，覆盖旧存档迁移、解锁阈值、星阶突破、经验溢出、携带快照和结算倍率。

### P1：玩法深化候选

1. 评估是否在开局准备页显示本局宠物技能数值。
2. 评估宠物专属任务、好感度或互动奖励，且需检查对核心玩法的影响。
3. 评估主动技能及其与烈焰/道具的互斥关系。
4. 评估详情页是否需要天气、蚂蚁目标/咬击和材质耐久等效果预览。

### P2：美术与性能候选

1. 若将来引入 Kenney 等外部矢量资源，先确认采用意图，再记录具体来源、文件和许可证信息。
2. 评估将 SVG 路径拆分为独立资源文件。
3. 在设备验证后评估 reduced-motion、屏幕外暂停和动画预算。
4. 只有出现 HUD 性能问题时，再评估把技能反馈转成位图或精灵图。
5. 评估互动、升级、升星和技能触发音效；采用前核对来源和许可证并登记。

### P3：长期系统候选

宠物碎片/重复获得、活动、多宠物编队、云端同步和数据分析均为未实现构想；没有据此认定它们是当前产品方向或已承诺功能。
