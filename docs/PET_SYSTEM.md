# 宠物系统设计与实现文档

> 当前版本：第一版“月岩兔动态样板 + 五只宠物档案 + 单局效果框架”

## 1. 产品目标

宠物不是静态头像，而是随页面和关卡状态工作的动态伙伴：

- 主菜单点击“宠物”首先进入伙伴列表；点击卡片进入详情。
- 详情页支持查看技能、星级、等级、经验、解锁条件，并执行携带/取消携带。
- 宠物有独立的等级、星阶和技能矩阵；携带状态通过 `activePetId` 存档。
- 伙伴使用分层 SVG 与 CSS 动画：呼吸、漂浮、随机眨眼、耳朵/翅膀/尾巴摆动、点击互动和技能触发反馈。
- 进入游戏时生成一次宠物快照，确保本局能力稳定；结算时向携带宠物发放经验。

### 2.2 页面与交互

实现位置：`src/components/PetCenter.vue`、`src/components/AnimatedPet.vue`

- 列表页：当前同行伙伴、拥有数、解锁状态、等级经验条、星阶和技能摘要。
- 详情页：伙伴动态展示台、档案说明、等级经验、三段技能、星阶突破、携带/取消携带。
- 交互：点击宠物会触发跳跃/耳朵动作和提示；技能触发会让光环爆发。
- 响应式：列表卡片、详情大展示台与游戏 HUD 小尺寸均使用同一 SVG 组件。

### 2.3 存档与成长

实现位置：`src/core/storage.js`、`src/core/store.js`

```js
pets: {
  moonRabbit: { owned: true, level: 1, exp: 0, star: 1 },
  // 其他宠物按配置自动补齐
},
activePetId: 'moonRabbit'
```

- 旧存档自动补充宠物字段。
- 按历史关卡总星数自动同步解锁，避免旧玩家无法获得已满足条件的宠物。
- 等级上限为 `星阶 × 10`，最高 50 级。
- 星阶突破需要达到当前上限并消耗金币：2 星 500、3 星 1000、4 星 1800、5 星 3000。
- 通关或失败结算会按本局参与程度给携带宠物发放经验；中途放弃不发经验。

### 2.4 单局效果

实现位置：`src/core/petSystem.js`、`src/core/gameEngine.js`、`src/core/weather.js`、`src/core/attackSystem.js`

`createPetSnapshot()` 将存档状态转换为不可变的本局能力快照。`PetRuntime` 负责：

- 落层前扩大有效完美窗口，处理月岩兔的连携与一次性修正。
- 处理天气持续时间、天气开场强度与云盾。
- 处理飞行物额外伤害、击退奖励充能、直接攻击拦截。
- 处理余烬充能、烈焰结束修补与火焰护层。
- 处理最终金币倍率与结算经验。

游戏 HUD 以小尺寸动态宠物徽章展示当前等级与技能状态；宠物技能触发时通过 `noticeSeq` 同步到动画组件。

## 3. 动画实现规范

### 图层

`AnimatedPet.vue` 目前内置五种原创 SVG 造型，按角色拆分为 body、head、eye、ear、wing、tail、halo/accessory、aura 等部分。后续替换为外部 CC0 矢量底稿时，应保持这些图层语义，不直接导入 GIF。

### 动画节奏

- 呼吸：2.5 秒轻微缩放。
- 漂浮：3.2 秒上下浮动。
- 眨眼：2.2～6.0 秒随机间隔，闭眼约 140ms。
- 翅膀：云母精灵约 0.72 秒一拍；技能触发时加快。
- 耳朵/尾巴：4～5 秒错相位摆动。
- 点击互动：约 0.9 秒跳跃、摆耳并发出提示。
- 技能触发：约 0.95 秒光环爆发，由 HUD `noticeSeq` 触发。

列表页使用完整 SVG 但控制尺寸；未来可对屏幕外卡片暂停动画，游戏 HUD 只保留轻量状态动画。

## 4. 资源与许可证

第一版使用项目内原创 SVG 样板，没有新增外部二进制资源。后续若导入资源，优先采用 Kenney Animal Pack Remastered/Redux 的 CC0 矢量底稿，拆分、重绘并保留本项目动画图层；来源与修改必须登记在根目录 `ASSET_LICENSES.md`。

参考资源与适用方式：

- Kenney Animal Pack Remastered：2D、CC0，适合作为动物基础造型。
- Kenney Animal Pack Redux：30 种动物、每种 8 种样式，含 vector/spritesheet；适合作为兔、鸟、猫头鹰等造型参考。
- Bevouliin Free Flying Bird：CC0，适合研究扇翼帧序列。
- Cat & Dog、Animated Wild Animals、Meca Dog：CC0，但偏像素/横版成品，仅用于动作节奏参考，不直接混入当前矢量 UI。
- Animals pack：CC-BY 3.0，若使用必须署名 Olga Bikmullina，不作为默认依赖。

## 5. 后续未开发计划

### P0：第一版验收与补强

1. 在真实手机尺寸检查列表、详情、HUD 的触控区域与安全区。
2. 为五只宠物补充更明确的技能事件动作：云盾张翼、铆钉犬冲刺、燧星狐火轨、星辉猫抓取金币。
3. 增加动画组件单元测试：随机眨眼、触发动作可重置、卸载后定时器清理。
4. 增加回归测试：旧存档迁移、解锁阈值、星阶突破、经验溢出、携带快照和结算倍率。

### P1：玩法深度

1. 将宠物技能说明接入准备页，让玩家在开局前看到本局实际数值。
2. 增加宠物专属任务、好感度和互动奖励，但不改变核心堆叠公平性。
3. 支持宠物技能的主动按钮或充能主动技，并与现有烈焰/道具互斥规则统一。
4. 将天气、飞行物、材质抗性等效果显示在宠物详情的“实战预览”中。

### P2：美术与性能

1. 用户确认后下载并登记 Kenney CC0 矢量资源，替换或扩充当前样板造型。
2. 将宠物 SVG 的重复路径抽取为资源文件，减少组件体积。
3. 对低端设备增加 `prefers-reduced-motion`、屏幕外暂停和 CSS 动画预算控制。
4. 若 HUD DOM 浮层影响性能，再将技能反馈导出 WebP/spritesheet 并由 Canvas 播放。
5. 增加音效：互动、升级、升星、技能触发、护盾/拦截，优先使用已核验的 CC0 生物音效并记录来源。

### P3：长期系统

1. 宠物碎片、重复获得转换、限时活动与收藏图鉴。
2. 多宠物编队或“主宠物 + 被动伙伴”组合；需要先明确数值上限避免叠加失控。
3. 云端存档与跨设备同步；当前 localStorage 方案继续作为离线兜底。
4. 数据分析：携带率、技能触发率、失败原因，用于平衡等级、星阶和金币成本。
